# Garner — Backend Implementation Plan

This directory contains the complete phased implementation plan for the Garner backend.

## Phase order

1. [Foundation and Architecture](01-foundation-and-architecture.md)
2. [Identity, Security, and Catalog](02-identity-security-and-catalog.md)
3. [Shopping Lists and Sessions](03-shopping-lists-and-sessions.md)
4. [Pricing and Crowdsourcing](04-pricing-and-crowdsourcing.md)
5. [Price Intelligence](05-price-intelligence.md)
6. [External Price Sources](06-external-price-sources.md)
7. [Smart Shopping Optimization](07-optimization.md)
8. [Notifications, Hardening, and Production Readiness](08-notifications-hardening-and-production.md)

The product/business flows are derived from the Garner business specification, while the implementation choices follow the Garner backend architecture specification.

Each phase is intended to be executed by an implementation agent independently, while preserving the global architecture and domain boundaries.
