# Phase 0.5 — Environment & Framework Setup

## Objective

Set up the core development environment, install the framework, and configure the necessary tools before proceeding with the architectural foundation. This ensures a standardized, reproducible local environment for all subsequent phases.

## 1. Prerequisites & Tooling

Ensure the local machine has the required system dependencies:
- **Node.js** (v20+ recommended)
- **pnpm** or **npm** (pnpm recommended for monorepos/fast installs)
- **Docker & Docker Compose** (for running PostgreSQL and Redis locally)
- **Git**

## 2. Framework Initialization

Initialize the NestJS application:
- Run `npx @nestjs/cli new garner-backend --strict`
- Choose the package manager (pnpm/npm).
- Clean up the boilerplate code (remove default `app.controller.ts`, `app.service.ts` if not needed, keep a basic health check).
- Configure TypeScript (`tsconfig.json`) for strict mode and correct path aliases (e.g., `@/` pointing to `src/`).

## 3. Linter & Formatter Setup

Configure code quality tools:
- **ESLint**: Set up rules for NestJS, TypeScript, and import sorting (e.g., `eslint-plugin-import`).
- **Prettier**: Configure `.prettierrc` for consistent formatting.
- **Husky & lint-staged** (Optional but recommended): Set up pre-commit hooks to format and lint code automatically.

## 4. Docker Compose Environment

Create a `docker-compose.yml` file at the root to spin up local infrastructure:
- **PostgreSQL**: A single Postgres container.
  - An initialization script (`init.sql`) mapped to `/docker-entrypoint-initdb.d/` to create the three logical databases: `core_db`, `pricing_db`, `intelligence_db`.
- **Redis**: A Redis container for BullMQ and caching.

## 5. Prisma ORM Setup

Initialize Prisma for database access:
- Install Prisma CLI and client (`prisma`, `@prisma/client`).
- Set up multiple Prisma schemas if necessary, or a single schema organized for the three databases (Note: Prisma natively supports one database per schema, so we will need three separate schemas and generated clients: `prisma/core/schema.prisma`, `prisma/pricing/schema.prisma`, `prisma/intelligence/schema.prisma`).
- Configure `.env` with the three database connection strings.

## 6. Testing Framework

Configure Jest for both Unit and E2E tests:
- NestJS comes with Jest by default.
- Configure `jest.config.ts` for unit tests.
- Set up a separate `jest-e2e.json` and testing environment for integration tests (e.g., using testcontainers or a dedicated test database).

## 7. Environment Variables Configuration

Set up configuration management:
- Install `@nestjs/config` and `joi` or `zod` for environment variable validation.
- Create a `.env.example` file documenting all required variables (Database URLs, Redis URL, JWT Secret, Port, etc.).

## Agent Acceptance Criteria

- [ ] NestJS project is generated and runs via `npm run start:dev`.
- [ ] `docker-compose up -d` successfully starts PostgreSQL (with 3 DBs) and Redis.
- [ ] Prisma is initialized and can connect to the local databases.
- [ ] Linter and formatter pass without errors.
- [ ] Tests run successfully.
- [ ] `.env.example` is complete and documented.

## Deliverable

A clean, compiling NestJS repository with working local infrastructure (Docker Compose) and configured tooling, ready for Phase 1 architectural scaffolding.
